# HR-Workforce-Analytics-Employee-Insight
 
HR Workforce Analytics & Employee Insights  —  Data Analyst
Workforce analytics dashboards enabling HR leadership to monitor performance, recruitment, attrition, diversity, and compensation trends.
Built automated ETL workflows and SQL scripts for HR data extraction and monthly MIS reporting.
Developed Tableau dashboards covering Attrition, Diversity, Recruitment Funnel, Performance, and Headcount analysis.
Generated predictive insights into employee attrition and workforce trends, partnering with HR stakeholders on KPI definitions.
Technologies: SQL, Tableau, Python, Excel VBA, ETL
